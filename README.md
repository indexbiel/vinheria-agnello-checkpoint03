
# Vinheria Agnello - Checkpoint 03

## Descrição

Sistema de controle de estoque da Vinheria Agnello, desenvolvido em JavaScript. O projeto utiliza objetos, arrays e funções de alta ordem para organizar e consultar os vinhos cadastrados.

## O que foi implementado

- Array de objetos contendo os vinhos, com nome, tipo, safra e estoque.
- `adicionarVinho()` - adiciona novos vinhos ao estoque.
- `listarVinhos()` - lista todos os vinhos utilizando forEach.
- `mostrarEstoqueBaixo()` - mostra os vinhos com menos de 5 unidades utilizando filter.
- `calcularEstoqueTotal()` - calcula a quantidade total de vinhos utilizando reduce.
- `mostrarNomesMaiusculos()` - exibe os nomes dos vinhos em letras maiúsculas utilizando map.
- Página HTML com descrição do sistema e estilização em CSS.
- Exibição dos resultados utilizando console.log e alert().

## Resultados exibidos

- Lista completa de vinhos.
- Vinhos com estoque abaixo de 5 unidades.
- Quantidade total de vinhos em estoque.
- Nomes dos vinhos em letras maiúsculas.
